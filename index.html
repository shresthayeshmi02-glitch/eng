01 — Introduction

What is Voice?

Voice tells us whether the subject does an action or the action is done to the subject/object.

Simply, it shows whether the subject is doing an action or receiving an action.

Example

Ram writes a letter. → Ram does the action.

A letter is written by Ram. → A letter receives the action.

02 — Types

Types of Voice

Active Voice

The subject performs the action.

Example: Ram writes a letter.

Here Ram is the subject and performs the action. Ram is the subject and doer.

Passive Voice

The action is done to the subject.

The receiver of the action is the subject.

Example: A letter is written by Ram.

Here, the subject does not do the action. The action is done to the subject. Simply, the subject receives the action.

03 — Uses

Uses of Voice

Uses of Active Voice

Active voice is generally used when:

  • We want the sentence to be clear and direct.
  • We want to emphasize who performed the action.
  • We want writing to be short and simple.

Uses of Passive Voice

Passive voice is used when:

  • The doer is unknown.
  • The doer is unimportant.
  • We want to emphasize the action or receiver.
04 — Rules

Rules for Conversion

  • Object becomes Subject.
  • Subject becomes Object.
  • Main verb changes to V³.
  • Add a suitable helping verb.
  • Use by + doer if needed.
  • If there is no object, passive voice is usually not possible.

07 — Two Objects

Conversion with Two Objects

Some sentences contain two objects: a direct object and an indirect object.

When a sentence has two objects, either object can become the subject of the passive voice. However, the indirect object is often made the subject because it sounds more natural.

Example

Active: The teacher taught us English.

Passive: We were taught English by the teacher.

Passive: English was taught to us by the teacher.

Parts of the Sentence

The teacher → Subject

taught → Verb

us → Indirect Object

English → Direct Object
